# vivoicons — 包名校验/已扫描包名/队列页 Tab/搜索/批量导入

## 1. APK 校验 + 已扫描包名识别
- **包名强校验**：解析后 APK 包名必须为 `com.vivo.simpleiconthemeres`，否则按解析失败处理并提示「包名不符，请选择 SimpleIconThemeRes.apk」
- Step1 初始提示文案改为：「请从 /system/app/SimpleIconThemeRes/ 提取 SimpleIconThemeRes.apk」
- **扫描已有包名**：`ApkPatcher.loadInfo` 遍历 drawable 类型全部资源名，匹配 `^(.+)_b_s5_1x1_(mc|sc|bg)$`，前缀部分 `_`→`.` 还原为包名（如 `vstudio_android_camera360_b_s5_1x1_bg` → `vitudio.android.camera360`）；同一包名的 mc/sc/bg 归并，结果放入 `ApkInfo.existingPackages`
- **防重复导入**：Step2 确认时若包名与已扫描包名重复（不区分大小写）→ 拒绝加入队列并提示「该包名已存在于目标 APK 中，避免资源 id 冲突」；批量导入同样跳过并计数
- 背景选择框上方增加一行「已扫描出 XXX 个包名，请在右上角查看」，与下方内容用白色分隔线隔开

## 2. 队列页 Tab：已添加 / 已扫描 + 搜索
- QueueManagerScreen 顶部加 `TabRow`：**已添加(n)** / **已扫描(n)**
  - 已添加 = 原有功能原样（列表/左滑编辑删除/多选/详情弹窗）
  - 已扫描 = 纯只读列表（同样式圆角卡，无编辑/删除/滑动/多选），不计入队列与徽章
- **两个 Tab 都有搜索框**（filled 圆角，Tab 下方）：输入实时子串过滤（忽略大小写）
- **定位交互**：列表始终全量显示；输入关键词时底部出现匹配结果条，点击某条 → 滚动定位到该项（scrollToItem）并高亮该卡片约 1.5 秒

## 3. 批量导入（选文件夹）
- Step2 增加「批量导入（选择文件夹）」按钮，`OpenDocumentTree` 选文件夹（新增依赖 `androidx.documentfile:documentfile`）
- 读取文件夹内 `.xml` 文件，按文件名解析：`<包名下划线>_b_s5_1x1_mc.xml` / `_sc.xml`（`_`→`.` 还原包名）；同包名归并、必须有 mc，只有 sc 的跳过
- **重复处理**：
  - 命名不合规 / 与已扫描包名重复 → 跳过并计数
  - **与队列中已有包名重复 → 覆盖替换原条目**（与手动确认行为一致），计入「覆盖 K 个」
- 每条以 SAF document Uri 存入队列（与手动添加同构，可编辑/删除/参与注入），tree uri 申请持久授权
- UI 提示固定文案：「请正确命名文件，如 com_coolapk_market_b_s5_1x1_mc.xml / _sc.xml」；导入完成弹圆角结果对话框「成功导入 N 个包（覆盖 K 个），跳过 M 个」
